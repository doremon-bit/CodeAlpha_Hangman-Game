# CodeAlpha_Hangman-Game

## Description

This is a simple text-based Hangman game developed using Python. The player has to guess a hidden word one letter at a time. The player gets 6 incorrect attempts before the game ends.

## Features

- Random word selection
- Letter-by-letter guessing
- 6 incorrect attempts allowed
- Win and lose conditions
- Simple console-based gameplay

## Concepts Used

- Python Lists
- Strings
- While Loop
- If-Else Statements
- Random Module
- User Input and Output

## How to Run

1. Install Python.
2. Save the file as `hangman.py`.
3. Run:

```bash
python hangman.py
```
